这是**冻结基准（FROZEN）**，不是实验记录。

**规则：本文件写入后不得修改。** 需要替换基准时，新建 `01_baseline_xxx.md`，在其中说明为何替换、旧基准哪里失效。

## 6. 与官方 README 的差异及根因

官方 README 公布：超额不含成本 17.83%，含成本 12.90%。与本次实测相差约 5 个百分点。

**根因不是我们做错了，是 README 的数字已过期六年。**

时间线：

```
2020-11-26   README 写入 0.178316（git log -S 可查）     ← 当时版本 v0.6.0
2023-01-10   PR #1407 修复涨跌停成交逻辑
             原文："check limit_up/down should consider direction"
             即：旧版涨停时不允许卖出、跌停时不允许买入，属逻辑错误
2023-2024    #1291 成交金额计算 bug 修复、#1262 模拟器重构 …
2026-10-08   v0.9.8
2026-10-20   本次实测 8.07%
```

**决定性证据：上游完全对齐，只有回测环节不同。**

| 环节 | 官方 | 本次 | 判定 |
|---|---|---|---|
| IC | 0.0448 | 0.0468 | 一致 |
| ICIR | 0.366 | 0.38 | 一致 |
| RankIC | 0.0486 | 0.0490 | 一致 |
| RankICIR | 0.372 | 0.41 | 一致 |
| 含成本年化 | 12.90% | 8.07% | 不同 |

特征、标签、训练数据、模型全部一致（所以 IC 一致），差异只出在成交撮合环节——而那部分官方自己改过好几次。

**官方真正的验收标准也不是 17.83%。** `tests/test_all_pipeline.py` 的断言是：

```python
self.assertGreaterEqual(
    analyze_df.loc(axis=0)["excess_return_with_cost", "annualized_return"].values[0],
    0.05,          # 含成本年化 ≥ 5% 即通过
    "backtest failed",
)
```

官方测试套件实测 `3 passed`（训练 / 回测 / 实验记录）。8.07% 通过，余量 60%。

**结论：不要追 17.83%。它是一个不可复现的历史展示数字，且生成它的代码含已被修复的错误。**

## 8. 已知偏差（这些不能当没看见）

| 偏差 | 影响 | 未来必须做的事 |
|---|---|---|
| `deal_price=close` | 收盘价成交，实盘难以保证 | 改为 next_open 或 VWAP 复测，看衰减多少 |
| `limit_threshold=0.095` 全局固定 | 创业板/科创板是 20%，ST 是 5%，当前阈值不适用 | 按板块分层设定 |
| 无冲击成本 | 50 只票、日换手 10%，小市值标的影响显著 | 引入按成交额比例的成本模型 |
| 数据源为 Yahoo | 缺失停牌标记、退市股处理不明、复权可能有误 | 换聚宽后复权 + 复权因子重跑，对比差异 |
| 无 PIT 财务数据 | 因子全是价量，不涉及财报，暂不暴露问题 | 一旦加入基本面因子，PIT 立即成为硬约束 |
| 股票池 3875 只，回测只用 csi300 | 幸存者偏差风险未知 | 明确历史成分与退市处理方式 |

## 9. 晋升标准（未来实验的对照规则）

新实验要被认定为「有改进」，必须**同时**满足：

1. 含成本超额年化 **> 8.07%**
2. 信息比率 **> 0.91**
3. 最大回撤不劣于 **−8.61%**
4. 在**样本外区间**上成立（不许在训练区间上比）
5. 记录了试错次数，并给出 PBO 或多重检验校正后的显著性

第 4 条和第 5 条是防自欺的核心。**只满足 1-3 而不满足 4-5 的结果，一律视为噪音，不写入 journal。**

## 附：本次暴露的问题（已固化）

1. `pip install pyqlib` 带来的 mlflow 3.x 与 qlib 不兼容 → 锁定 `mlflow==2.11.3` + `setuptools<81`
2. macOS 上 lightgbm 报 `Library not loaded: @rpath/libomp.dylib` → `brew install libomp`
3. 在含 `qlib/` 源码的目录下运行会遮蔽已安装包，并报 `No module named 'qlib.data._libs.rolling'` → 源码必须编译安装，且运行目录不能包含 `qlib/` 包
4. qlib 测试代码 `shutil.rmtree(cls.URI_PATH.lstrip("file:"))` 有 bug：`lstrip` 会剥离所有 `f/i/l/e/:` 字符，把绝对路径变成相对路径，在 cwd 下创建假目录 → 正确写法应为 `removeprefix`
